A make.fun bounty entry: a tiny pure-stdlib Python program that writes one
original line — an alien tourist's two-day review of planet Earth — to
`entry.txt`.

## Run

```sh
python3 main.py
```

It writes `entry.txt` to `MAKEFUN_OUTPUT_DIR`, `/output`, or `out/`,
whichever is writable first.

## The line

"Two days on Earth: gorgeous sunsets, undrinkable oceans, and a species that pays rent to live on its own planet. 2/5, would not rebook."

One line, 135 characters, deterministic: every run writes the same bytes.
